CI — ตรวจงาน

รวมโค้ดแล้ว build และรัน checks/tests เพื่อจับปัญหาก่อนเผยแพร่

CD — ส่งมอบงาน

นำ artifact เดิมที่ผ่าน checks ไป deploy ยัง environment ที่กำหนด โดยไม่ build ซ้ำคนละชุด
